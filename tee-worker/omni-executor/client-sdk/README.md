# Omni Client Packages

This repository contains packages that are published on NPM for dApps to interact with the Heima Protocol.

Learn more about it on [Heima's official documentation](https://docs.heima.network/parachain/sdk-documentation).

## Packages

- `@heima-network/client-sdk` ([go-to](packages/client-sdk/README.md)): provides helpers for dApps to interact with the Heima Protocol
- `@heima-network/chaindata` ([go-to](packages/chaindata/README.md)): provides chain information of Heima networks.
